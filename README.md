# Delivery Fee Calculator

This program calculates a delivery fee based on the order price total and the delivery day.

## Setup

conda activate aigc5005
pip install -r requirements.txt

## Run

python delivery_calculator.py

## Example

Enter order price total: 56
Enter the delivery day (all the letters lowercase): sunday
Order price total: $56.0
Delivery day: sunday
Delivery fee: $0.0

## Known limitations

The program only accepts delivery days written in lowercase.
The program does not allow users to re-enter an invalid value.
